Rust Learning Notes
==================

Rust is a systems programming language focused on safety and performance.
Cargo is Rust's build tool and package manager.
A Rust project usually has a Cargo.toml file.
The main source file is often src/main.rs.

Variables and Types
-------------------
Use let to declare a variable.
Use mut when a variable needs to change.
A String owns its text data.
A string slice is written as &str.
The println! macro prints formatted output.
The format! macro builds a String.

Control Flow
------------
An if expression runs code when a condition is true.
A for loop can iterate over a collection.
The while loop repeats while its condition is true.
The match expression handles different cases.
Use break to exit a loop early.
Use continue to skip to the next iteration.

Functions
---------
Functions are declared with fn.
Parameters need types.
A function can return a value.
The final expression in a function can be its return value.
Keep functions small and focused.

Ownership and Borrowing
-----------------------
Each value has an owner.
When the owner goes out of scope, the value is dropped.
A reference lets you borrow a value.
Use & to create an immutable reference.
Use &mut to create a mutable reference.
Avoid cloning data unless you actually need a copy.

Files and Errors
----------------
The std::fs module provides filesystem operations.
The read_to_string function reads a file into a String.
File operations can fail.
Result represents success or failure.
The question mark operator can propagate an error.
A missing file should produce a useful error message.
